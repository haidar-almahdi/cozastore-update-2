# وصف متطلب: حذف مستخدم (Admin - Delete User)

## نظرة عامة
هذا المتطلب يسمح للمدير بحذف مستخدم.

---

## الفاعلون (Actors)
- **Admin (المدير)**: مدير النظام

---

## الشروط المسبقة (Preconditions)
1. المدير مسجل دخول في النظام
2. المستخدم المراد حذفه موجود في النظام

---

## الشروط اللاحقة (Postconditions)
1. يتم حذف المستخدم من قاعدة البيانات
2. يتم حذف جميع البيانات المرتبطة بالمستخدم

---

## السيناريو الأساسي (Main Flow)

### 1. حذف المستخدم
- المدير يضغط "Delete" على مستخدم
- النظام يطلب تأكيد الحذف
- المدير يؤكد
- النظام يحذف المستخدم

---

## السيناريوهات البديلة (Alternative Flows)

### A1: إلغاء الحذف
- **الشرط**: المدير يتراجع عن الحذف.
- **الإجراء**:
  - في نافذة التأكيد، يضغط المدير "Cancel".
  - لا يتم حذف المستخدم.

### A2: حذف النفس
- **الشرط**: المدير يحاول حذف حسابه الخاص.
- **الإجراء**:
  - النظام يمنع العملية.
  - النظام يعرض رسالة "لا يمكنك حذف حسابك الحالي".

## السيناريوهات الاستثنائية (Exceptional Flows)

### E1: المستخدم غير موجود
- **الشرط**: المستخدم تم حذفه مسبقاً.
- **الإجراء**:
  - النظام يعرض رسالة "المستخدم غير موجود".
  - يتم تحديث القائمة.

### E2: خطأ قاعدة البيانات
- **الشرط**: فشل عملية الحذف في قاعدة البيانات.
- **الإجراء**:
  - النظام يعرض رسالة خطأ.
  - لا يتم حذف المستخدم.

---

### Input (المدخلات):
- **user_id**: معرف المستخدم (required|exists:users,id)

### Output (المخرجات):
- حذف المستخدم من جدول `users`
- حذف السجلات المرتبطة (مثل الطلبات، السلة، المفضلات) تلقائياً (Cascade Delete) أو التعامل معها
- عرض رسالة نجاح

> **ملاحظة**: لا يمكن للمدير حذف حسابه الشخصي (Self-deletion prevention).

## الجداول المتأثرة (Affected Tables)
1. **users**: حذف المستخدم

---

## الاختبار (Testing)
1. ✅ حذف مستخدم بنجاح
