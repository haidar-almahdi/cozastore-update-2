# وصف متطلب: تسجيل الدخول (Login)

## نظرة عامة
هذا المتطلب يسمح للمستخدم المسجل بتسجيل الدخول إلى النظام.

---

## الفاعلون (Actors)
- **User (المستخدم)**: مستخدم مسجل يريد الدخول للنظام

---

## الشروط المسبقة (Preconditions)
1. المستخدم لديه حساب في النظام
2. المستخدم غير مسجل دخول حالياً

---

## الشروط اللاحقة (Postconditions)
1. يتم تسجيل دخول المستخدم
2. يتم إنشاء جلسة (Session)
3. يتم إعادة توجيه المستخدم للصفحة المطلوبة أو الرئيسية

---

## السيناريو الأساسي (Main Flow)

### 1. الوصول لصفحة تسجيل الدخول
- المستخدم يضغط على "Login"
- النظام يعرض نموذج تسجيل الدخول

### 2. إدخال البيانات
- المستخدم يدخل البريد الإلكتروني
- المستخدم يدخل كلمة المرور
- المستخدم يختار "تذكرني" (اختياري)

### 3. تسجيل الدخول
- المستخدم يضغط "Login"
- النظام يتحقق من البيانات
- النظام يتحقق من كلمة المرور

### 4. إنشاء الجلسة
- النظام ينشئ جلسة للمستخدم
- إذا اختار "تذكرني"، النظام ينشئ Remember Token
- النظام يعيد التوجيه للصفحة المطلوبة

---

## السيناريوهات البديلة (Alternative Flows)

### A1: بيانات خاطئة
- **الشرط**: البريد أو كلمة المرور خاطئة
- **الإجراء**: 
  - النظام يعرض "بيانات الدخول غير صحيحة"

### A2: حقول فارغة
- **الشرط**: البريد أو كلمة المرور فارغة
- **الإجراء**:
  - النظام يعرض "الرجاء ملء جميع الحقول"

---

## قواعد العمل (Business Rules)

1. **المحاولات الفاشلة**: بعد 5 محاولات فاشلة، يتم حظر الحساب مؤقتاً
2. **Remember Me**: يبقى المستخدم مسجل دخول لمدة 30 يوم
3. **Redirect**: بعد تسجيل الدخول، يتم التوجيه للصفحة المطلوبة أو الرئيسية

---

## البيانات المطلوبة (Required Data)

### Input (المدخلات):
- **email**: البريد الإلكتروني (required|string|email)
- **password**: كلمة المرور (required|string)
- **remember**: تذكرني (boolean)

### Output (المخرجات):
- تسجيل دخول المستخدم (Session creation)
- دمج سلة الزائر مع سلة المستخدم (Cart merging)
- redirect to intended page or home

> **ملاحظة**: يتم دمج السلة تلقائياً عند تسجيل الدخول.
