# وصف متطلب: إضافة منتج إلى المفضلة (Add to Favorites)

## نظرة عامة
هذا المتطلب يسمح للمستخدم المسجل بإضافة منتج إلى قائمة المفضلة الخاصة به.

---

## الفاعلون (Actors)
- **Customer (المستخدم)**: المستخدم المسجل الذي يريد إضافة منتج للمفضلة

---

## الشروط المسبقة (Preconditions)
1. المستخدم مسجل دخول في النظام
2. المنتج موجود ونشط في النظام
3. المنتج غير موجود مسبقاً في المفضلة

---

## الشروط اللاحقة (Postconditions)
1. يتم إضافة المنتج إلى قائمة المفضلة
2. يتم تحديث أيقونة القلب لتصبح ممتلئة
3. يتم تحديث عداد المفضلة في الـ Header

---

## السيناريو الأساسي (Main Flow)

### 1. اختيار المنتج
- المستخدم يتصفح المنتجات
- المستخدم يجد منتج يعجبه
- المستخدم يضغط على أيقونة القلب (♡)

### 2. التحقق من تسجيل الدخول
- النظام يتحقق من تسجيل دخول المستخدم
- إذا لم يكن مسجل دخول، يتم توجيهه لصفحة تسجيل الدخول

### 3. إضافة للمفضلة
- النظام يتحقق من عدم وجود المنتج في المفضلة
- النظام ينشئ سجل جديد في جدول favorites
- النظام يربط المنتج بالمستخدم

### 4. تحديث الواجهة
- النظام يغير أيقونة القلب لتصبح ممتلئة (♥)
- النظام يحدث عداد المفضلة في الـ Header
- النظام يعرض رسالة نجاح "تمت الإضافة للمفضلة"

---

## السيناريوهات البديلة (Alternative Flows)

### A1: المنتج موجود مسبقاً في المفضلة
- **الشرط**: المستخدم يحاول إضافة منتج موجود بالفعل
- **الإجراء**: 
  - النظام يعرض رسالة "المنتج موجود بالفعل في المفضلة"
  - لا يتم إنشاء سجل مكرر

### A2: مستخدم غير مسجل دخول
- **الشرط**: المستخدم يحاول إضافة منتج بدون تسجيل دخول
- **الإجراء**:
  - النظام يعرض رسالة "يجب تسجيل الدخول أولاً"
  - النظام يعيد توجيه المستخدم لصفحة تسجيل الدخول
  - بعد تسجيل الدخول، يتم إضافة المنتج تلقائياً

### A3: منتج غير موجود أو محذوف
- **الشرط**: المنتج تم حذفه أو تعطيله
- **الإجراء**:
  - النظام يعرض رسالة خطأ "المنتج غير متوفر"
  - لا يتم إضافة المنتج للمفضلة

---

## قواعد العمل (Business Rules)

1. **التفرد**:
   - كل منتج يمكن إضافته مرة واحدة فقط للمستخدم الواحد
   - لا يسمح بتكرار نفس المنتج في المفضلة

2. **الصلاحيات**:
   - فقط المستخدمين المسجلين يمكنهم إضافة منتجات للمفضلة
   - المستخدم يمكنه إضافة عدد غير محدود من المنتجات

3. **التحديث الفوري**:
   - يتم تحديث الواجهة فوراً بدون إعادة تحميل الصفحة (AJAX)
---

## الجداول المتأثرة (Affected Tables)

1. **favorites**: إدراج سجل جديد
2. **products**: قراءة بيانات المنتج
3. **users**: التحقق من المستخدم

## الأمان (Security)

1. المستخدم يجب أن يكون مسجل دخول (Authenticated)
2. التحقق من صحة product_id
3. استخدام CSRF Token
4. منع SQL Injection

---

## الأداء (Performance)

1. استخدام AJAX لتحديث الواجهة بدون إعادة تحميل
2. استخدام Database Indexes على user_id و product_id
3. Cache لعدد المفضلة
