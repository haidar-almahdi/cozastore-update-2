# وصف متطلب: عرض قائمة المستخدمين (Admin - View Users)
### Output (المخرجات):
- **users**: قائمة المستخدمين (paginated 10)
- **links**: روابط التنقل بين الصفحات

> **ملاحظة**: يتم عرض المستخدمين مرتبين حسب تاريخ الإنشاء (latest).
## نظرة عامة
هذا المتطلب يسمح للمدير بعرض قائمة جميع المستخدمين.

---

## الفاعلون (Actors)
- **Admin (المدير)**: مدير النظام

---

## الشروط المسبقة (Preconditions)
1. المستخدم مسجل دخول كمدير

---

## السيناريو الأساسي (Main Flow)

### 1. عرض القائمة
- المدير يفتح صفحة المستخدمين
- النظام يعرض جميع المستخدمين مع:
  - الاسم
  - البريد الإلكتروني
  - الدور
  - تاريخ التسجيل
  - أزرار (عرض، تعديل، حذف)

---

## السيناريوهات البديلة (Alternative Flows)

### A1: لا يوجد مستخدمين
- **الشرط**: لا يوجد مستخدمين مسجلين (غير المدير).
- **الإجراء**:
  - النظام يعرض رسالة "لا يوجد مستخدمين مسجلين".

### A2: البحث عن مستخدم
- **الشرط**: المدير يبحث عن مستخدم بالاسم أو البريد.
- **الإجراء**:
  - المدير يدخل نص البحث.
  - النظام يعرض النتائج المطابقة.

## السيناريوهات الاستثنائية (Exceptional Flows)

### E1: فشل تحميل البيانات
- **الشرط**: خطأ في قاعدة البيانات.
- **الإجراء**:
  - النظام يعرض رسالة خطأ "فشل تحميل قائمة المستخدمين".
  - يظهر زر "إعادة المحاولة".
