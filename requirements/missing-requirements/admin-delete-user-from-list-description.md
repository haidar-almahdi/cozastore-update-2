# وصف متطلب: حذف مستخدم من قائمة المستخدمين من قبل الأدمن

## نظرة عامة
هذا المتطلب يسمح للأدمن بحذف مستخدم من قائمة المستخدمين.

## الفاعلون (Actors)
- **Admin (المدير)**

## الشروط المسبقة (Preconditions)
1. المستخدم موجود.
2. ليس المستخدم الحالي للأدمن نفسه.

## الشروط اللاحقة (Postconditions)
1. يتم حذف المستخدم من النظام.
2. يتم تحديث قائمة المستخدمين.

## السيناريو الأساسي (Main Flow)
1. الأدمن يضغط حذف.
2. النظام يطلب تأكيد.
3. الأدمن يؤكد.
4. النظام يحذف المستخدم.

## السيناريوهات البديلة (Alternative Flows)
### A1: إلغاء التأكيد
- يتم إلغاء العملية ولا يتم الحذف.

## البيانات المطلوبة (Required Data)
### Input:
- `user_id`

### Output:
- success/fail message
