# وصف متطلب: فتح نموذج إضافة مستخدم من قبل الأدمن

## نظرة عامة
هذا المتطلب يسمح للأدمن بالوصول إلى شاشة إنشاء مستخدم جديد.

## الفاعلون (Actors)
- **Admin (المدير)**

## الشروط المسبقة (Preconditions)
1. الأدمن مسجل دخول.

## الشروط اللاحقة (Postconditions)
1. يظهر نموذج إضافة مستخدم.

## السيناريو الأساسي (Main Flow)
1. الأدمن يفتح صفحة المستخدمين.
2. يضغط زر إضافة مستخدم.
3. النظام يعرض نموذج الإنشاء.

## البيانات المطلوبة (Required Data)
### Output:
- صفحة `create user form`
