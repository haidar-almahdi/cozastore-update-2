# وصف متطلب: فتح نموذج تعديل مستخدم من قبل الأدمن

## نظرة عامة
هذا المتطلب يسمح للأدمن بالدخول إلى صفحة تعديل بيانات مستخدم محدد.

## الفاعلون (Actors)
- **Admin (المدير)**

## الشروط المسبقة (Preconditions)
1. المستخدم موجود.

## الشروط اللاحقة (Postconditions)
1. يظهر نموذج تعديل المستخدم مع بياناته الحالية.

## السيناريو الأساسي (Main Flow)
1. الأدمن يضغط زر تعديل المستخدم.
2. النظام يجلب بيانات المستخدم.
3. النظام يعرض نموذج التعديل.

## البيانات المطلوبة (Required Data)
### Input:
- `user_id`

### Output:
- edit form pre-filled
